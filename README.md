# 🛒 TechMarket – E-Commerce Web Application

**TechMarket** is a simple yet functional e-commerce website developed as part of a university **Web Development** module. The application allows users to sign up, log in, and browse technology products organized by categories. It demonstrates the fundamentals of front-end and back-end integration using HTML, CSS, JavaScript, and PHP.

## 🌐 Features

- 👤 User Authentication (Sign Up / Login)  
- 🖥️ Product Listings by Categories:  
  - Laptops & Computers  
  - Smartphones  
  - Gaming Consoles  
  - Smartwatches  
- 💡 Dark Mode Toggle (JavaScript)  
- 🔗 Product Details via dynamic `product.php?id=...`  
- 📐 Table-based layout (for educational demonstration)

---

## 🚀 How to Run Locally

1. Clone the Repository:
```bash
git clone https://github.com/yourusername/TechMarket.git
cd TechMarket
```

2. Start a PHP server:
```bash
php -S localhost:8000
```

3. Open your browser at:
```
http://localhost:8000/templates/index.html
```

> Make sure PHP is installed (or use XAMPP/WAMP).
